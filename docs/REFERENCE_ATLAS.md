# Subject reference cards (Scoolabs, author-curated)

These 32 educational reference cards supplement the existing 40 science concepts and 48 apparatus descriptions. They are authored summaries, **not** scraped or automatically generated from an external provider. Labels, formulas and scientific names are included for learning, but independent teacher review is still required.

The physics cards cover eleven introductory relationships and examples, with stated assumptions. Biology cards illustrate ten common microscope specimens and plant/animal structures, not clinical claims. Agricultural Science cards introduce eleven crops and livestock categories relevant to Nigerian classrooms, without pretending to offer field prescriptions, disease diagnoses, or fertilizer dosing.

For sourced **numeric** constants, Scoolabs uses the separate NIST 2022 CODATA data file generated via GitHub Actions and documented in [SCIENCE_DATA_SOURCES.md](SCIENCE_DATA_SOURCES.md). Do not misattribute these author-curated text summaries to NIST, GBIF, IUPAC or agricultural extension providers.

Before deployment, a qualified teacher should verify age appropriateness, local curriculum alignment, scientific accuracy and reading level.
